The independent native-audio/vorbis.wasm codec, native-vorbis.js adapter,
native-audio-resampler.js, native-music-stream.js, native-pcm-voice.js and
native-sound-engine.js playback components
derive from Visual Pinball's miniaudio/stb_vorbis integration at:
https://github.com/vpinball/vpinball/tree/195f214dd4849b8ef6113fd377258b78d0dec3bf

scripts/build-native-vorbis.mjs reproduces the subset from the pinned compiled
reference engine (SHA-256 c9f81fc78eff4ae994ac06272870e4572aa4fce00adf7194a78ef65c1b04e4d8).
native-audio/vorbis.json records the retained original function-body hashes,
codec API, data regions and resulting artifact identity. Native source PCM
observations and independent complete-track tests are retained in the repo.
The module exposes only decoder, allocation and memory exports. It has no
player initialization and imports only the heap-growth callback.
