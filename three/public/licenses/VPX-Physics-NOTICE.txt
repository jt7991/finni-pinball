Reference version used by vpinball-wasm 0.3.4:
195f214dd4849b8ef6113fd377258b78d0dec3bf
https://github.com/vpinball/vpinball/tree/195f214dd4849b8ef6113fd377258b78d0dec3bf/src/physics

native-bumper.js adapts BumperHitCircle::Collide in physics/collideex.cpp.
native-slingshot.js adapts LineSegSlingshot::Collide in the same file.
native-hit-event.js preserves shape-specific Hit dispatch, native ball event
history filtering and SetupHitObject event metadata from collide.cpp,
collideex.cpp, and parts/surface.cpp, primitive.cpp, rubber.cpp and ramp.cpp.
native-target-event.js preserves target triangle/edge/point event eligibility,
incoming thresholds, animation arming and target-specific event history from
collide.cpp, collideex.cpp and parts/hittarget.cpp.
native-orientation.js adapts HitBall::UpdateDisplacements and Matrix3's scalar
SkewSymmetric, MulMatricesAndMulScalar and OrthoNormalize from hitball.cpp
and math/matrix.h. It retains native Float32 row-major matrix integration.
ball-spin.js and gate.js retain the reference wasm32 engine's compiled Float32
operation order for spin damping and gate rebounds, respectively. Complete
native gate memory recordings verify those scalar operations without changing
authored damping parameters, collision bounds or input timing.
native-ramp.js also preserves GetRampVertex's compiled reciprocal multiplication
for cumulative ramp-height/width interpolation. Read-only native triangle and
ball-state recordings verify the resulting contact geometry and launch paths.
plunger.js preserves the compiled HitPlunger::Collide reciprocal factors for
the fixed rod mass; unchanged native WASM impulse recordings cover varied
ball masses and the resulting reverse recoil.
Its manual Fire calculation also retains the compiled reciprocal factors
from Plunger::Fire and PlungerMoverObject::Fire, verified by unchanged native
function recordings and complete per-frame ball-state launch captures.
native-flipper-contact.js includes HitFlipper::Collide event timing and speed
arguments. full-game.js also preserves Flipper::get_CurrentAngle conversion:
https://github.com/vpinball/vpinball/blob/195f214dd4849b8ef6113fd377258b78d0dec3bf/src/parts/flipper.cpp
native-sound.js adapts SoundPlayer::Play pitch variation and frequency math:
https://github.com/vpinball/vpinball/blob/195f214dd4849b8ef6113fd377258b78d0dec3bf/src/audio/SoundPlayer.cpp

impulse-plunger.js adapts cvpmImpulseP from the same revision's scripts/core.vbs:
https://github.com/vpinball/vpinball/blob/195f214dd4849b8ef6113fd377258b78d0dec3bf/scripts/core.vbs

The JavaScript adaptation retains native float position and angular-momentum
integration, uses Three.js world units for contact queries, analytic tapered
flipper contacts. The complete native path advances positions and ball orientation
directly; Rapier supplies body records and the optional integration fallback.
Its source is included in
the three/ directory alongside the build scripts and dependency manifest.
